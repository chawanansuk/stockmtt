# stockmtt — ตัดสต๊อกสินค้าจากรูปใบเขียนมือด้วย AI

แอพง่าย ๆ สำหรับร้านฮาร์ดแวร์: พนักงานเขียนใบเบิก/ใบรับของด้วยมือ → ถ่ายรูป → AI (Claude)
อ่านและจับคู่กับรายการสินค้าให้อัตโนมัติ → ตรวจ/แก้ก่อนยืนยัน → ระบบหัก/เพิ่มยอดให้

## ความสามารถ
- 📷 ถ่ายรูปใบรายการ แล้ว AI อ่านลายมือภาษาไทย จับคู่กับสินค้าในระบบ (มี prompt caching ลดค่าใช้จ่าย)
- ➖➕ ตัดออก (เบิก) และ รับเข้า (ของเข้า) ในที่เดียว — แนบรูปใบจริงเก็บไว้ดูย้อนหลังได้
- ✏️ มีหน้าตรวจทาน แก้สินค้า/จำนวนได้ก่อนบันทึก (กันอ่านผิด)
- 📦 ติดตามยอดคงเหลือ + ตั้ง “จุดสั่งซื้อ” แจ้งเตือนของใกล้หมด
- 💰 ราคาทุนต่อหน่วย + หน่วยนับ → เห็นมูลค่าสต๊อกรวม และมูลค่าใน CSV (snapshot ทุน ณ วันบันทึก)
- 📋 โหมดนับสต๊อกจริง: เดินนับทั้งร้าน เทียบกับระบบ แล้วปรับยอดเป็นใบเดียว
- ↩ ยกเลิกรายการที่ทำผิดแล้วคืนสต๊อกได้ — ทั้งใบ หรือเฉพาะบางแถวในใบ
- 🕘 ประวัติทุกการเคลื่อนไหว (รวม “ปรับยอด” ที่แก้ด้วยมือ) กรองตามประเภท/ช่วงวันที่/รายสินค้า + โหลดทีละหน้า
- 📱 ใช้งานผ่านเว็บบนมือถือได้เลย (ติดตั้งเป็นแอพ/PWA ได้)
- 🔎 กรองสต๊อกตามหมวด/โกดัง + ค้นหา
- ✏️ แก้ไขชื่อ/หมวด/หน่วย/ทุน และลบสินค้าได้ในหน้าเว็บ
- 📤 ส่งออกสต๊อก/ประวัติเป็นไฟล์ Excel (.csv รองรับภาษาไทย) + 💾 ดาวน์โหลดข้อมูลสำรองทั้งหมด (JSON)
- 🧠 ระบบจำคำย่อ: ยิ่งยืนยันรายการ AI ยิ่งจับคู่คำที่เคยเจอแม่นขึ้น
- 🔒 ล็อกอินด้วยรหัสผ่านร่วม (ตั้ง `APP_PASSWORD`) + security headers + จำกัดอัตราการเรียก API
- 🔐 PIN เจ้าของ (ตั้ง `APP_ADMIN_PIN`): พนักงานตัด/รับของได้ แต่แก้/ลบ/ยกเลิก/ปรับยอดต้องใส่ PIN
- 📨 แจ้งเตือนของใกล้หมดผ่าน LINE วันละครั้ง (ตั้งค่า LINE Messaging API — ดู `.env.example`)
- 👤 บันทึกผู้ทำรายการ/ผู้ยกเลิก (audit) — ลบสินค้าแบบ soft-delete (ซ่อนจากรายการ แต่ประวัติยังอยู่)

## วิธีที่ 1: รันบนคอมในร้าน (ฟรี, ข้อมูลอยู่ในเครื่อง)

เหมาะเมื่ออยากใช้ในร้าน ให้มือถือต่อ Wi-Fi เดียวกับคอม

1. ติดตั้ง **Node.js** (เวอร์ชัน 22 ขึ้นไป) จาก https://nodejs.org
2. ตั้งค่า API key: คัดลอก `.env.example` เป็น `.env` แล้วใส่ `ANTHROPIC_API_KEY`
   (ขอ key ที่ https://platform.claude.com) — ถ้าต้องการให้ล็อกอินก่อนใช้ ใส่ `APP_PASSWORD` ด้วย
3. เปิดแอพ:
   - **Windows:** ดับเบิลคลิก `start.bat`
   - **Mac/Linux:** เปิด Terminal แล้วรัน `bash start.sh`
   - หรือสั่งเอง: `npm install` แล้ว `npm start`
4. หน้าจอจะขึ้น **ลิงก์ + QR code** → เปิดบนคอมที่ `http://localhost:3000`
   หรือ **สแกน QR ด้วยมือถือ** (ที่อยู่ Wi-Fi เดียวกัน) เพื่อเปิดใช้งานบนมือถือ

> ข้อมูลทั้งหมดเก็บในโฟลเดอร์ `data/` ของเครื่อง — ควรสำรองไฟล์เป็นระยะ

## วิธีที่ 2: ขึ้นออนไลน์ (เปิดได้ทุกที่ ผ่านลิงก์)

ใช้ฐานข้อมูลถาวร (Postgres) ข้อมูลไม่หายแม้รีสตาร์ท — ทำครั้งเดียว ใช้ฟรี

### ขั้นที่ 1 — สร้างฐานข้อมูลฟรีที่ Neon
1. สมัคร https://neon.tech (ฟรี ไม่ต้องใช้บัตร)
2. สร้าง Project → คัดลอก **Connection string** (ขึ้นต้นด้วย `postgresql://...`)

### ขั้นที่ 2 — deploy เว็บที่ Render
1. สมัคร https://render.com (ฟรี)
2. กด **New +** → **Web Service** → เชื่อม GitHub repo `chawanansuk/stockmtt`
   (Render จะอ่านไฟล์ `render.yaml` ให้อัตโนมัติ)
3. ตั้งค่า **Environment Variables**:
   - `ANTHROPIC_API_KEY` = key จาก Claude
   - `DATABASE_URL` = connection string จาก Neon (ขั้นที่ 1)
   - `APP_PASSWORD` = รหัสผ่านร่วมสำหรับเข้าเว็บ (แนะนำให้ตั้ง — กันคนนอกเข้าใช้/เปลืองเครดิต AI)
4. กด **Create / Deploy** รอสักครู่
5. เปิดลิงก์ที่ได้ เช่น `https://stockmtt.onrender.com` ใช้งานได้เลยทุกที่

ครั้งแรกที่เปิด ระบบจะนำเข้ารายการสินค้าตั้งต้น (จาก `data/products.json`) เข้าฐานข้อมูลให้อัตโนมัติ

> หมายเหตุแผนฟรีของ Render: ถ้าไม่มีคนใช้สักพักเว็บจะ “พักหลับ” พอเปิดครั้งแรกจะช้า ~30 วิ แล้วใช้ได้ปกติ (ข้อมูลไม่หาย)

## นำเข้ารายการสินค้าจาก Excel

```bash
npm run import -- /path/to/รายการสินค้า.xlsx
```
- คอลัมน์ A = ชื่อสินค้า, คอลัมน์ B = จำนวนเริ่มต้น (ถ้ามี), ชื่อชีต = หมวด/โกดัง
- ตัวเลือก: `--no-header` (แถวแรกเป็นข้อมูลเลย ไม่ใช่หัวกระดาษ), `--category=ชื่อ` (ตั้งชื่อหมวดเอง)
- ข้อมูลถูกบันทึกที่ `data/products.json` (รวมกับของเดิม เก็บยอดคงเหลือไว้)

ตอนนี้แนบมาแล้ว 171 รายการ 3 หมวด: เปา, ตู้เหลือง, โกดัง 42

## ขั้นตอนใช้งาน
1. แท็บ **ตัด/รับ** → เลือกโหมด (ตัดออก/รับเข้า) → ถ่ายรูป → กด **อ่านด้วย AI**
2. ตรวจรายการที่ AI อ่านได้ แก้สินค้า/จำนวนได้ → (เลือกแนบรูปใบ) → กด **ยืนยัน**
3. แท็บ **สต๊อก** ดู/แก้ยอด, ตั้งจุดสั่งซื้อ/หน่วย/ราคาทุน, เพิ่มสินค้าใหม่, กด 📜 ดูการเคลื่อนไหวรายสินค้า
4. โหมด **นับสต๊อกจริง**: กดเริ่มนับ → กรอกเฉพาะตัวที่นับ → ยืนยัน ระบบปรับยอดเป็นใบเดียว
5. แท็บ **ประวัติ** กรอง/โหลดเพิ่ม, ดูรูปใบที่แนบ, **ยกเลิก** ทั้งใบหรือกด ✕ เฉพาะบางแถว

### แจ้งเตือน LINE (ไม่บังคับ)
1. สร้าง channel แบบ **Messaging API** ที่ https://developers.line.biz แล้วออก **Channel access token**
2. ตั้ง env: `LINE_CHANNEL_ACCESS_TOKEN` และ `LINE_TO` (= Your user ID ในหน้า channel หรือ groupId) แล้วเพิ่มบอทเป็นเพื่อน
3. ระบบส่งสรุปของใกล้หมดวันละครั้งหลังเวลา `NOTIFY_HOUR` (ค่าเริ่มต้น 8 โมงเช้าไทย) — มีปุ่ม “ทดสอบแจ้งเตือน LINE” ในแท็บสต๊อก
4. แผนฟรีของ Render เว็บหลับได้ — ตั้งตัว ping ฟรี (เช่น UptimeRobot ยิง `/healthz` ทุก 5–10 นาที) เพื่อให้แจ้งเตือนตรงเวลา

## โครงสร้างโปรเจกต์
```
server.js              เซิร์ฟเวอร์ + API
lib/claude.js          เรียก Claude อ่านรูป + จับคู่สินค้า (prompt caching)
lib/notify.js          แจ้งเตือนของใกล้หมดผ่าน LINE (Messaging API)
lib/auth.js            ระบบล็อกอิน (รหัสผ่านร่วม + session cookie + PIN เจ้าของ)
lib/errors.js          คลาส error ที่ส่งข้อความให้ผู้ใช้ได้อย่างปลอดภัย
lib/store.js           เลือกที่เก็บข้อมูลอัตโนมัติ (Postgres ถ้ามี DATABASE_URL, ไม่งั้น JSON)
lib/store-pg.js        ที่เก็บข้อมูลแบบ PostgreSQL (ออนไลน์)
lib/store-json.js      ที่เก็บข้อมูลแบบไฟล์ JSON (ในเครื่อง)
lib/xlsx.js            อ่านไฟล์ .xlsx (ไม่ต้องพึ่ง library)
scripts/import-xlsx.js สคริปต์นำเข้าจาก Excel
public/                หน้าเว็บ (มือถือ)
test/                  เทสต์ตรรกะฐานข้อมูล (npm test)
render.yaml            ตั้งค่า deploy ขึ้น Render
data/products.json     รายการสินค้า + ยอดคงเหลือ (ใช้เป็นข้อมูลตั้งต้น)
```

## หมายเหตุ
- ใช้โมเดล `claude-opus-4-8` (รองรับการอ่านรูป/ลายมือภาษาไทย) — รายการสินค้าถูกแคช (prompt caching)
  ถ่ายใบติด ๆ กันภายใน 5 นาที จ่ายค่า token ส่วนรายการสินค้าราว 10% ของปกติ
- ค่าใช้จ่าย AI คิดตามการใช้งานของ Claude API (ต่อการอ่าน 1 รูป)
- รูปใบที่แนบเก็บล่าสุดไม่เกิน `IMAGE_KEEP` รูป (ค่าเริ่มต้น 400 — กันฐานข้อมูลฟรีเต็ม) และไม่รวมอยู่ในไฟล์สำรอง JSON
- ทดสอบตรรกะฐานข้อมูล: `npm test`
