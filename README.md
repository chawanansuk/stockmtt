# stockmtt — ตัดสต๊อกสินค้าจากรูปใบเขียนมือด้วย AI

แอพง่าย ๆ สำหรับร้านฮาร์ดแวร์: พนักงานเขียนใบเบิกของด้วยมือ → ถ่ายรูป → AI (Claude)
อ่านและจับคู่กับรายการสินค้าให้อัตโนมัติ → ตรวจ/แก้ก่อนยืนยัน → ระบบหักยอดคงเหลือให้

## ความสามารถ
- 📷 ถ่ายรูปใบเบิก แล้ว AI อ่านลายมือภาษาไทย จับคู่กับสินค้าในระบบ
- ✏️ มีหน้าตรวจทาน แก้สินค้า/จำนวนได้ก่อนตัดจริง (กันอ่านผิด)
- 📦 ติดตามยอดคงเหลือของทุกสินค้า (ตั้งค่า/แก้ไขได้)
- 🕘 เก็บประวัติการตัดสต๊อกทุกครั้ง
- 📱 ใช้งานผ่านเว็บบนมือถือได้เลย

## ติดตั้งและใช้งาน

### 1) ติดตั้ง
```bash
npm install
```

### 2) ตั้งค่า API key ของ Claude
คัดลอก `.env.example` เป็น `.env` แล้วใส่ค่า key (ขอได้ที่ https://platform.claude.com)
```bash
cp .env.example .env
# แก้ไฟล์ .env ใส่ ANTHROPIC_API_KEY=sk-ant-...
```

### 3) (ทำครั้งแรก) นำเข้ารายการสินค้าจาก Excel
```bash
npm run import -- /path/to/รายการสินค้า.xlsx
```
- คอลัมน์ A = ชื่อสินค้า, คอลัมน์ B = จำนวนเริ่มต้น (ถ้ามี), ชื่อชีต = หมวด/ตู้
- แถวแรกของแต่ละชีตถือเป็นหัวกระดาษ (ข้ามให้อัตโนมัติ)
- ข้อมูลถูกบันทึกที่ `data/products.json` (โปรเจกต์นี้แนบไฟล์ตัวอย่างที่นำเข้าไว้แล้ว)

### 4) เปิดใช้งาน
```bash
npm start
```
เปิดเบราว์เซอร์ที่ `http://localhost:3000`

> ใช้บนมือถือในร้าน: ให้มือถืออยู่ Wi‑Fi เดียวกับเครื่องที่รันแอพ แล้วเข้า
> `http://<ไอพีของเครื่อง>:3000` (เช่น `http://192.168.1.50:3000`)

## ขั้นตอนการทำงาน
1. แท็บ **ตัดสต๊อก** → ถ่ายรูป/เลือกรูปใบเบิก → กด **อ่านด้วย AI**
2. ตรวจรายการที่ AI อ่านได้ แก้สินค้า/จำนวนได้ตามต้องการ
3. กด **ยืนยันตัดสต๊อก** → ระบบหักยอดและบันทึกประวัติ
4. แท็บ **สต๊อก** ดู/แก้ยอดคงเหลือ และเพิ่มสินค้าใหม่
5. แท็บ **ประวัติ** ดูรายการที่ตัดไปแล้ว

## โครงสร้างโปรเจกต์
```
server.js              เซิร์ฟเวอร์ + API
lib/claude.js          เรียก Claude อ่านรูป + จับคู่สินค้า
lib/store.js           อ่าน/เขียนข้อมูลสินค้า + ประวัติ (ไฟล์ JSON)
lib/xlsx.js            อ่านไฟล์ .xlsx (ไม่ต้องพึ่ง library)
scripts/import-xlsx.js สคริปต์นำเข้าจาก Excel
public/                หน้าเว็บ (มือถือ)
data/products.json     รายการสินค้า + ยอดคงเหลือ
data/transactions.json ประวัติการตัดสต๊อก (สร้างอัตโนมัติ)
```

## หมายเหตุ
- ใช้โมเดล `claude-opus-4-8` (รองรับการอ่านรูป/ลายมือภาษาไทย)
- ค่าใช้จ่าย AI คิดตามการใช้งานของ Claude API (ต่อการอ่าน 1 รูป)
- ข้อมูลทั้งหมดเก็บเป็นไฟล์ในเครื่อง — หากนำขึ้นเซิร์ฟเวอร์จริง ควรสำรอง `data/` เป็นระยะ
